# proveza-profile

Portfólio pessoal de Miguel Proveza, desenvolvedor full stack.

Feito com Next.js, React e Tailwind CSS.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Editando o conteúdo

Todo o texto do site fica em [`data/profile.ts`](data/profile.ts).
